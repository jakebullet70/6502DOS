:HELP
HELP [topic]
  Prints the help on topic. With no topic it lists the topics.
  HELP SHELL tells about the shell's statements.
  HELP DISKFREE
  DISKFREE, DISKINFO, DATE, TIME, UPTIME, MEM and WHERE work at the prompt
  and in a script.
  EXIST is for scripts and prints nothing.
  Each puts its result in P1$ for a script to test.
  SILENT prints nothing, not even an error. An error empties P1$.
:EXIST
EXIST name                     (Script only)
  For scripts. Tells whether the file or directory name exists.
  Name is one file. Wildcards are not allowed.
  Sets P1$ to 1 or 0. Prints nothing.
  EXIST DOCS\README.TXT
  IF P1$ = "1"
    PRINT "Found the readme"
  ENDIF
:DISKFREE
DISKFREE [d:] [SILENT]          (Command line or Script)
  Tells the free kilobytes of drive d, or of the current drive.
  Prints a line such as 877 KB free. Sets P1$ to the number, such as 877.
  At the prompt: DISKFREE C:
  In a script:   DISKFREE C: SILENT
                 PRINT P1$
:DISKINFO
DISKINFO [d:] [SILENT]          (Command line or Script)
  Tells the size of drive d, or of the current drive.
  Prints five numbers and sets P1$ to P5$ to them:
    P1$ KB total      P2$ KB free      P3$ bytes a cluster
    P4$ clusters      P5$ clusters free
  At the prompt: DISKINFO C:
  In a script:   DISKINFO C: SILENT
                 PRINT P2$ + " KB free of " + P1$
:DATE
DATE [yyyy-mm-dd] [SILENT]      (Command line or Script)
  Tells the date with its weekday, such as Sun 2026-10-18.
  With a date, sets the clock and prints nothing. The year is 2000 to 2099.
  Sets P1$ to the date, P2$ to the weekday,
  P3$ to P5$ to the year, month and day.
  At the prompt: DATE 2026-10-18
  In a script:   DATE SILENT
                 PRINT "Today is " + P1$
:TIME
TIME [hh:mm[:ss]] [SILENT]      (Command line or Script)
  Tells the time in 24 hours, such as 13:45:07.
  With a time, sets the clock and prints nothing.
  The seconds are 0 when left out.
  Sets P1$ to the time, P2$ to P4$ to the hours, minutes and seconds.
  At the prompt: TIME 13:45
  In a script:   TIME SILENT
                 PRINT "It is " + P1$
:UPTIME
UPTIME [SILENT]                 (Command line or Script)
  Tells the time since boot, such as 0 days 01:12:33.
  Sets P1$ to the seconds since boot, P2$ to the days, P3$ to the rest.
  At the prompt: UPTIME
  In a script:   UPTIME SILENT
                 PRINT "Up " + P1$ + " seconds"
:MEM
MEM [SILENT]                    (Command line or Script)
  Tells the free low RAM, the program area: 38655 bytes low RAM free.
  Tells the free 8 KB RAM banks, such as 53 banks free, 424 KB.
  Sets P1$ to the number of free banks and P2$ to the free low RAM bytes.
  At the prompt: MEM
  In a script:   MEM SILENT
                 PRINT "Free banks: " + P1$ + ", low RAM: " + P2$
:WHERE
WHERE name [SILENT]             (Command line or Script)
  Tells the path of the program the shell runs for name.
  Prints a path such as C:\DOS\HEAD.COM.
  A name with no extension is looked for as .SCOM, then .COM, then .CMD.
  Sets P1$ to the path, or to an empty string when nothing is found.
  At the prompt: WHERE HEAD
  In a script:   WHERE HEAD SILENT
                 IF P1$ = "" PRINT "No HEAD"
:SHELL
The shell runs a line typed at the prompt, or a line of a script.
The first word is a statement, an alias or a program. Case does not matter.
  The statements, each with its topic:
  BEEP BIND CD CHDIR CLS COLOR COPY DEL DELETE DIR END ENDIF ENDREP FILES
  GOSUB GOTO IF INPUT LIST LOCATE MD MKDIR ONERROR PAUSE PRINT RD REM REN
  RENAME REPEAT RETURN RMDIR RUN SETSYS TYPE VER VERSION WAIT
  name = expression sets a variable. There is no LET.
  A program is a .SCOM, .COM or .CMD file. See HELP WHERE.
  See also HELP SCRIPTS, VARIABLES, EXPRESSIONS, REDIRECT and PROMPT.
:SCRIPTS
A script is a text file NAME.CMD of shell lines. Typing NAME runs it.
  The words after NAME go in P1$ to P9$, one each.
  C:\STARTUP.CMD runs when the shell starts.
  A line holds up to 127 characters. Lines end in LF or CR LF.
  An error prints its message and the line, such as in C:\T.CMD line 3,
  and ends the script. See HELP ONERROR.
  Ctrl+C asks Terminate CMD job (Y/N)? Y ends the script.
  A program run from a script goes back to it. A script run from a script
  ends the first one.
  A label is a name of 2 characters or more and a colon, on its own line.
  IF blocks, REPEAT, GOTO and GOSUB work only in a script.
:VARIABLES
The variables of the shell:
  A to Z hold whole numbers. A$ to Z$ hold strings of up to 255 characters.
  P1$ to P9$ hold the words after a program's name. A command such as
  DISKFREE puts its results there. Running a program empties them first.
  PATH$, PROMPT$, EDITOR$ and TEMP$ are the system variables. See HELP SETSYS.
  CURDIR$ is the current drive and directory. It is read only.
  name = expression sets a variable.
  A = 5
  A$ = CURDIR$ + "\DOCS"
:EXPRESSIONS
The numbers and the strings of the shell:
  A number is whole, from -32768 to 32767. It takes + - * / and brackets.
  * and / come before + and -. / gives a whole number.
  A color name such as RED is a number. See HELP COLORS.
  A string is text in quotes, a string variable or CURDIR$. + joins strings,
  up to 255 characters. A quote with no closing quote runs to the line end.
  A file name may be a string, so a variable can hold it: DELETE A$
  A = (B + 2) * 3
  A$ = "C:\" + P1$
:PRINT
PRINT [item] [; item]...        (Command line or Script)
  Prints numbers and strings, then a new line. A ; between items adds
  nothing. A ; at the end keeps the cursor on the line.
  A number prints with no spaces around it.
  PRINT "A is "; A
  PRINT "Name: " + A$;
:INPUT
INPUT variable                  (Command line or Script)
  Prints ? and reads a line into variable. A number variable takes the
  number the line starts with, or 0.
  INPUT A$
  INPUT N
:IF
IF condition statement          (Command line or Script)
IF condition ... ENDIF          (Script only)
  Runs statement when condition holds. There is no THEN and no ELSE.
  The condition compares two numbers or two strings with =, <>, <, >, <= or
  >=. Strings compare by character code, so case counts.
  A condition alone on its line starts a block up to its ENDIF. When the
  condition fails, the lines of the block are skipped. Blocks nest.
  IF A > 9 PRINT "Big"
  IF P1$ = ""
    PRINT "Give a name"
    END
  ENDIF
:ENDIF
ENDIF ends an IF block. See HELP IF.
:REPEAT
REPEAT count ... ENDREP         (Script only)
  Runs the lines up to the ENDREP count times. count is 1 to 255. Below 1
  the lines are skipped. Loops nest.
  Up to 16 loops and GOSUBs are open at once. A GOTO out of a loop leaves
  it open.
  REPEAT 3
    PRINT "Hello"
  ENDREP
:ENDREP
ENDREP ends a REPEAT loop. See HELP REPEAT.
:GOTO
GOTO label                      (Script only)
  Goes on at the line after the line label:. The label is looked for from
  the start of the script. A label not found gives Label not found.
  IF P1$ = "" GOTO usage
  PRINT "Name: " + P1$
  END
  usage:
  PRINT "Give a name"
:GOSUB
GOSUB label                     (Script only)
  Goes to label as GOTO does. RETURN goes back to the line after the GOSUB.
  GOSUBs nest. RETURN with no GOSUB gives RETURN without GOSUB.
  GOSUB show
  END
  show:
  PRINT "In show"
  RETURN
:RETURN
RETURN ends a GOSUB. See HELP GOSUB.
:ONERROR
ONERROR 1   or   ONERROR 0      (Script only)
  ONERROR 1: after an error the script goes on at the next line.
  ONERROR 0: an error ends the script. A script starts with ONERROR 0.
  ONERROR 1
  DELETE OLD.TXT
  ONERROR 0
:END
END                             (Command line or Script)
  Ends the script. At the prompt it ends the shell.
:REM
REM text   or   ' text   or   // text
  A comment. The shell skips the rest of the line.
:RUN
RUN name [arguments]            (Command line or Script)
  Runs the program or script name, as typing name does. In a script, the
  script ends there. name may be a string, so a variable can hold it.
  RUN A$ DOCS\README.TXT
:FILES
FILES [pattern]   or   DIR      (Command line or Script)
  Lists the names that match pattern, or the current directory. Each name
  has its size or <DIR>. The count of names comes last.
  A directory as pattern lists the names in it.
  FILES
  DIR DOCS\*.TXT
:DIR
DIR is the same as FILES. See HELP FILES.
:LIST
LIST name   or   TYPE name      (Command line or Script)
  Prints the file name.
  LIST DOCS\README.TXT
:TYPE
TYPE is the same as LIST. See HELP LIST.
:COPY
COPY source target              (Command line or Script)
  Copies the file source to target. A target that is a directory takes the
  file under its own name. A source with * or ? copies each file that
  matches, and target must be a directory. Prints the count of files.
  COPY HELLO.TXT HI.TXT
  COPY DOCS\*.TXT BAK
:CHDIR
CHDIR name   or   CD name       (Command line or Script)
  Makes directory name the current directory.
  CHDIR DOCS
  CD ..
  CD \
:CD
CD is short for CHDIR. See HELP CHDIR.
:DELETE
DELETE name   or   DEL name     (Command line or Script)
  Deletes the file name.
  DELETE NEW\HI.TXT
:DEL
DEL is short for DELETE. See HELP DELETE.
:MKDIR
MKDIR name   or   MD name       (Command line or Script)
  Makes the directory name.
  MKDIR NEW
:MD
MD is short for MKDIR. See HELP MKDIR.
:RMDIR
RMDIR name   or   RD name       (Command line or Script)
  Removes the directory name. The directory must be empty.
  RMDIR NEW
:RD
RD is short for RMDIR. See HELP RMDIR.
:RENAME
RENAME old new  or  REN old new (Command line or Script)
  Renames the file old to new.
  RENAME NEW\HELLO.TXT NEW\HI.TXT
:REN
REN is short for RENAME. See HELP RENAME.
:VERSION
VERSION   or   VER              (Command line or Script)
  Prints the version of 6502DOS, such as 6502DOS V0.1.0.
  VERSION
:VER
VER is short for VERSION. See HELP VERSION.
:SETSYS
SETSYS [name = value]           (Command line or Script)
  Sets a system variable. With nothing after it, lists them.
  The system variables are PATH$, PROMPT$, EDITOR$ and TEMP$. They outlast a
  program. CURDIR$ is the current directory, read only.
  PATH$ holds the directories searched for a program, separated by ;.
  TEMP$ is the directory of the pipe files. Empty puts them in the root.
  SETSYS TEMP$ = "C:\TMP"
  PATH$ = "C:\DOS"
:BIND
BIND [name = command]           (Command line or Script)
  Makes name run command. The words typed after name follow the command.
  BIND alone lists the names. An empty command removes name.
  The commands share 255 characters.
  BIND H = HELP
  H IF
  BIND H =
:COLOR
COLOR foreground, background    (Command line or Script)
  Sets the color of the text printed after it. Each value is 0 to 15.
  The color names are numbers too. See HELP COLORS.
  COLOR WHITE, BLUE
  COLOR 5, 0
:COLORS
The color names, for COLOR and in any number:
  BLACK    0    PURPLE   4    ORANGE    8    GRAY       12
  WHITE    1    GREEN    5    BROWN     9    LIGHTGREEN 13
  RED      2    BLUE     6    LIGHTRED 10    LIGHTBLUE  14
  CYAN     3    YELLOW   7    DARKGRAY 11    LIGHTGRAY  15
  PRINT LIGHTGRAY * 16 + WHITE
:CLS
CLS                             (Command line or Script)
  Clears the screen.
:BEEP
BEEP                            (Command line or Script)
  Prints character 7, the bell.
:LOCATE
LOCATE row, column              (Command line or Script)
  Moves the cursor to row 0 to 29 and column 0 to 79, from the top left.
  LOCATE 10, 20
:WAIT
WAIT seconds                    (Command line or Script)
  Waits that many seconds. A key does not end the wait. Ctrl+C does.
  WAIT 2
:PAUSE
PAUSE                           (Command line or Script)
  Waits for a key. Prints nothing.
  PRINT "Press a key"
  PAUSE
:PROMPT
The keys and the quotes at the prompt:
  Tab completes the last word: a file or a directory, or, as the first word,
  a statement or a .SCOM, .COM or .CMD program on PATH$. Each Tab gives the
  next match, and Shift+Tab the one before.
  Up brings back the line before, and Down the line after. The last 8 lines
  are kept.
  A name with a space goes in quotes. Tab puts a match with a space in quotes.
  COPY HELLO.TXT "MY FILE.TXT"
  A program gets "MY FILE.TXT" whole in P1$ to P9$. Its command tail drops
  the quotes.
  PROMPT$ is the prompt. $P is the current drive and directory, $N the drive,
  $G >, $L <, $B |, $Q =, $_ a new line and $$ $. Empty shows C>.
  SETSYS PROMPT$ = "$P$G"
:REDIRECT
statement TO file   or   APPEND file   or   FROM file
statement | statement           (Command line or Script)
  TO sends the output of statement to file, made new.
  APPEND adds the output to the end of file, and makes file when missing.
  FROM reads the input of statement from file.
  | sends the output of a statement to the input of the next.
  The pipe files are PIPE1.$$$ and PIPE2.$$$ in TEMP$.
  TO, APPEND and FROM are words of their own, outside quotes.
  FILES TO LIST.TXT
  PRINT "Done" APPEND LOG.TXT
  LIST DOCS\LONG.TXT | GREP -n x | MORE
:TO
TO is a redirect. See HELP REDIRECT.
:APPEND
APPEND is a redirect. See HELP REDIRECT.
:FROM
FROM is a redirect. See HELP REDIRECT.
:VIEW
VIEW name                       (Command line only)
  Shows the text file name a page at a time.
  Up and Down move a line. PgUp and PgDn move a page. Space moves a page down.
  Home goes to the first line, End to the last page.
  Left and Right move the view 8 columns sideways.
  W turns wrap on and off.
  F or / asks for a text and finds it, in any case. N finds the next one.
  Q or Esc ends it.
  VIEW DOCS\README.TXT
:TREE
TREE [d:][path] [-F]            (Command line only)
  Draws every directory below path, or below the root, as a tree.
  -F lists the files of each directory too.
  TREE C:\DOCS -F
:MORE
MORE [file]                     (Command line only)
  Shows file, or the input, a screen at a time.
  -- More -- waits for a key. Ctrl+C ends it.
  MORE DOCS\README.TXT
  LIST DOCS\README.TXT | MORE
:HEAD
HEAD [-n count] [file]          (Command line only)
  Writes the first count lines of file, or of the input.
  count is 10 when left out.
  HEAD -n 20 DOCS\LONG.TXT
  LIST DOCS\LONG.TXT | HEAD
:TAIL
TAIL [-n count] [file]          (Command line only)
  Writes the last count lines of file, or of the input.
  count is 10 when left out.
  TAIL -n 20 DOCS\LONG.TXT
  LIST DOCS\LONG.TXT | TAIL
:GREP
GREP [-i] [-n] [-v] [-c] pattern [file] (Command line only)
  Writes each line of file, or of the input, that matches pattern.
  ^ is the start of the line, $ its end, and . any character.
  [abc] is one of a, b and c, [a-z] one of a to z, and [^abc] any other.
  * after one of these matches it 0 or more times. \. matches a dot.
  -i ignores case. -n writes the line numbers.
  -v writes the lines that do not match. -c writes only the count.
  GREP -n "^Line 0[1-3]" DOCS\LONG.TXT
  LIST DOCS\LONG.TXT | GREP -c "x.*z"
:XCOPY
XCOPY source [target] [-s] [-e] [-p] [-l] [-y] (Command line only)
  Copies the files of directory source, or the files that match a pattern,
  to directory target, or to the current directory. A missing target is made.
  -s copies the directories below too. -e copies the empty ones as well.
  -p asks before each file. -l lists the files and copies nothing.
  -y overwrites a file with no question. Without -y a file that exists asks
  Overwrite path (Y/N/A)? A overwrites the rest.
  Esc at a question stops the copy.
  XCOPY C:\DOCS C:\BAK -s
  XCOPY DOCS\*.TXT BAK -sp
:HELPBAS
HELPBAS [topic]                 (Command line only)
  Prints the help on the MSBASIC keyword topic, from C:\DOS\HELPBAS.HLP.
  With no topic it lists the topics. Small letters are the same as capitals.
  HELPBAS PRINT
  HELPBAS str$
:HDIR
HDIR [d:][path] [-1..-9] [-l] [-n -e -d -s] [-t] [-a] [-c] (Command line only)
  Lists the directories and files of path, or of the current directory,
  as a grid in colors. A path such as DOCS\*.TXT lists the names that match.
  Directories come first. Names sort by name, case aside.
  -e sorts by extension, -d by date, -s by size, -n by name.
  -1 to -9 set the number of columns, 2 when left out.
  -l runs the names across each row. -t shows the dates.
  -a skips hidden and system names. -c clears the screen first.
  -? lists the switches. Switches may share one -: -2le.
  The listing stops at each full screen. Esc or Ctrl+C there ends it.
  Output to a file or to NUL has no colors and no stops.
  HDIR is in C:\UTILS.
  HDIR C:\DOCS -1t
  HDIR *.COM -s
